# UltrON Admin Panel

The **UltrON Admin Panel** is the cloud-hosted web application built for remote monitoring and management of UltrON hardware deployments.

## Tech Stack
- React (Vite)
- Tailwind CSS
- Supabase (Auth & Database)

## Folder Structure
- `src/` — React frontend application
- `supabase/` — Supabase migrations, edge functions, and configuration

## Getting Started
1. `npm install`
2. `npm run dev`
3. The panel runs by default on `http://localhost:5173`.
