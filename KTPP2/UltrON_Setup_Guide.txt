========================================
   UltrON — New PC Setup Guide
========================================

Requirement: Windows 10/11 with WebView2 Runtime
             (built-in on Win11, auto-updates on Win10)

========================================
STEP 1 — INSTALL
========================================

1. Go to:  https://github.com/bitraneerajbabu/UltronPC/releases/latest
2. Download  UltrON_Installer.exe
3. Run it — it will:
   - Download UltrON.exe into  %LOCALAPPDATA%\UltrON\
   - Create a Desktop shortcut called "UltrON"
   - Launch UltrON automatically

========================================
STEP 2 — FIRST LAUNCH (Access Denied)
========================================

UltrON opens a native desktop window showing:

  "Access Denied — AMC Token is expired or not configured."

This is expected. The software needs a license key to activate.

========================================
STEP 3 — CLICK LOGO TO REVEAL LOGIN
========================================

Click the UltrON logo at the top of the card.
A login form appears titled:

  "AMC Token Renewal Override"

Enter:

  Username:  token
  Password:  Ultron123.0

Click "Authenticate".

========================================
STEP 4 — LICENSE & AMC SETUP
========================================

Now you see the "License & AMC Setup" form.

Fill in:

  Central API URL   https://rajapi.com/api/v1/sync/
  AMC Token         <paste your site uk_ key from rajapi.com dashboard>
  AMC Key           <optional — paste device uk_ key if needed>

Click "Test & Activate".

========================================
STEP 5 — NORMAL LOGIN
========================================

After activation, the real login screen appears:

  Username:  Master
  Password:  <the ADMIN_PASSWORD set during build>

  Default (if never changed): changeme

Click "Sign In".

========================================
STEP 6 — DONE
========================================

You are now in the UltrON dashboard.

From here on, every time you open UltrON.exe you only
need to do Step 5 (login with Master).

Steps 2-4 are one-time only.

========================================
  TROUBLESHOOTING
========================================

Problem: "Network error" during setup
  -> The local server did not start. Check Windows Firewall.

Problem: "Server rejected key"
  -> The AMC Token is wrong or expired. Check rajapi.com dashboard.

Problem: Logo click does nothing
  -> Click precisely on the UltrON logo image at top center.

Problem: Blank white window
  -> Close and reopen UltrON.exe. If persists, check
     %LOCALAPPDATA%\UltrON\ultron_log.txt

Problem: "WebView2 not found"
  -> Install Microsoft Edge WebView2 Runtime from:
     https://developer.microsoft.com/en-us/microsoft-edge/webview2/
